# 0001 電腦螢幕錄影與手機錄影之差異化壓縮策略

為解決 OBS 等電腦螢幕錄影二次壓縮後文字模糊問題，系統於 `BatchCompressor` 批次轉檔架構中導入「影片來源類型（手機錄影 vs 電腦螢幕錄影）」差異化機制。

## 決策內容

1. **自動判定與批次覆蓋 (Heuristic Auto-Detection & Batch Override)**：
   - 介面提供全域預設來源模式（Base Settings: `📱 手機錄影` / `💻 電腦螢幕錄影`）。
   - 單檔加入佇列時，經由 `detectVideoSourceType({ width, height })` 自動判定：
     - 直式影片（Height > Width）歸類為 `手機錄影`。
     - 超寬螢幕（21:9, 32:9）、16:10 螢幕、或寬度 $\ge 2560px$ 歸類為 `電腦螢幕錄影`。
     - 一般 16:9 橫向影片標註系統建議標籤，並允許使用者於批次清單項目中進行 1-click 單檔覆蓋。

2. **壓縮策略與參數差異**：
   - **📱 手機錄影 (Mobile Video)**：
     - `longEdge` 預設為 `1080`（自動降階以符合目標容量與順暢播放）。
     - `fps` 預設為 `'original'`（保持相機動態率）。
   - **💻 電腦螢幕錄影 (Screen Recording)**：
     - `longEdge` 預設為 `'original'`（保持點對點原始解析度，避免 2K/4K/程式碼截圖模糊）。
     - `fps` 預設為 `'30'`（若原始影片高於 30 FPS，優先降影格率以節省容量與提高單張銳利度）。
     - 於 UI 中提供調降解析度之文字模糊警示（`⚠️ 螢幕錄影降低解析度可能導致小字模糊`）。
